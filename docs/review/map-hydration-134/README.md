## Reproduce

Use Node22 and npm ci. Run npm test, npm run lint, npx tsc --noEmit, and npm run build. For guest browser checks, start npm run dev -- --hostname 127.0.0.1 --port 5361 and npm start -- --hostname 127.0.0.1 --port 5362, setting the two server-only guest variables above for each runtime. Install Playwright/Chromium separately. Run acceptance-browser.mjs with PLAYWRIGHT_MODULE pointing to its index.mjs and BIBBLE_SOURCE to the source checkout; optional BIBBLE_DEV_URL/BIBBLE_PROD_URL/BIBBLE_EVIDENCE_DIR override the two localhost addresses and ./bibble-acceptance. Fresh test browser profiles and synthetic maps are used. Authenticated backend behavior is intentionally outside these assertions.

Artifacts live on a fork-only evidence branch outside the source PR diff. Hosted CI, review, final labels, external merge and official credit remain separate states.
